# Broad test: 7 player types × 3 seeds × 10 days

Generated by `sim/broad.js` · engine 0.4.0 · default parameters · seeds 101, 202, 303 · 26 s.
Values are averages over the 3 seeds.

## Player types

- **teacher**: consistent language, teaches with ✅ ❤️ ❌ ❓, demonstrates when it waits. 3 sessions/day.
- **devoted**: like teacher, but plays every session until it falls asleep. 3 sessions/day.
- **shifter**: like teacher, but from day 6 on switches to a completely new language and new favourite emojis. 3 sessions/day.
- **affectionate**: lots of ❤️, loose language (60% consistent), sometimes picks up its emojis, never ❌. 3 sessions/day.
- **mirror**: mirrors its emojis, alternates, ✅ when it mirrors back. 3 sessions/day.
- **chaotic**: random emojis from the keyboard, random signs, no language. 3 sessions/day.
- **minimalist**: short sessions twice a day, passes 💬 a lot, few emojis. 2 sessions/day.

## Interpretation

| goal | result | verdict |
|---|---|---|
| consistency, can be moulded | Teacher-type players: first-try replies match their language 32% → ~45–50%. Loose players (affectionate 4–8%, minimalist 0–16%) mould almost nothing. | ok for strict teaching, weak for everyone else |
| not repetitive | Teacher/devoted/mirror: 24–31% of 3-emoji sequences repeat within a session, slightly growing. "Uneasy" (boredom) was **never** the strongest emotion in any session. | ✗ loops, no boredom |
| frequent surprises from the creature | 23–30% initiative moves for teachers, but mostly small variations and babble. New emojis: 1–2 per session. Invented games: 1–3% of moves. Déjà-vu memories: rare. | ~ quantity ok, little meaningful surprise |
| 5–10 min sessions when fully developed | Devoted player: stage 3 = 7.4 min (89 inputs), stage 4 = 9.8 min (116 inputs). | ✓ (upper end) |
| new stage every ~3 sessions | Teacher: stage 1/2/3 at session 3/4/5, then stage 4 rarely (1 of 3 seeds, session 10–25). **Affectionate and chaotic never leave stage 0; minimalist barely reaches 1.** | ✗ too fast early, stuck later, no growth without strict teaching |
| adapts to new tendencies | Shifter: after switching language, new-language replies stay at 0–27% for 5 days. Its old emojis keep filling "frequently used" (counted over all time), so the new words hardly repeat. | ✗ |
| early character persists, then changes | Inborn character: 60–70% of moves for creatures stuck at stage 0, 14–22% for teachers (never replaced). Emojis from days 1–2 are still **80–89%** of its emoji moves on days 9–10 (except the shifter). | ✗ early experience locks in, character never changes |
| (emotional range) | Only joyful and curious are ever dominant. Uneasy, sad and angry: 0% of sessions. | ✗ narrow |

**Main causes**
1. **Growth only counts confident rules.** Players who don't teach strictly produce few rules, so no
   growth. Strict teaching produces many rules quickly, so growth is very fast, and then the
   language consolidates and complexity stalls.
2. **Boredom only looks at the player's surprise.** The random half of the keyboard keeps the player
   surprising, so the creature never gets bored, however repetitive *it* is.
3. **Habits never wear off within a session**, and nothing pushes back against loops.
4. **"Frequently used" counts over all time.** Early emojis dominate the keyboard forever, so early
   experiences lock in and new tendencies can't establish themselves.
5. **The character is fixed for life.**
6. **Emotion triggers for unease, sadness and anger almost never fire.** Praise (✅ ❤️) and new emojis
   (curiosity) dominate.
