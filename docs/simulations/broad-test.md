# Broad test: 7 player types × 3 seeds × 10 days

Generated by `sim/broad.js` · engine 0.10.0 (simple core, docs/07) · default parameters · seeds 101, 202, 303 · 67 s.
Values are averages over the 3 seeds.

## Player types

- **teacher**: consistent language, teaches with ✅ ❌ ❓, demonstrates when it waits. 3 sessions/day.
- **devoted**: like teacher, but plays every session until it falls asleep. 3 sessions/day.
- **shifter**: like teacher, but from day 6 on switches to a completely new language and new favourite emojis. 3 sessions/day.
- **affectionate**: lots of ✅ for almost anything, loose language (60% consistent), sometimes picks up its emojis, never ❌. 3 sessions/day.
- **mirror**: mirrors its emojis, alternates, ✅ when it mirrors back. 3 sessions/day.
- **chaotic**: random emojis from the keyboard, random signs, no language. 3 sessions/day.
- **minimalist**: short sessions twice a day, passes (❓) a lot, few emojis. 2 sessions/day.
